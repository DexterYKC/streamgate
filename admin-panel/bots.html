🚨 Emergency Migration

If a bot gets banned, send a migration broadcast to all active subscribers from the current bot pointing them to the backup bot.

📋 How to add a backup bot

  1. Create a new bot on @BotFather → /newbot
  2. Copy the token and username
  3. In Render → Environment, add:
    TELEGRAM_TOKEN_2 = your new token
    BOT_USERNAME_2 = YourBackupBotUsername
  4. Redeploy — the webhook registers automatically
  5. If the primary bot gets banned, come here and send the migration broadcast
